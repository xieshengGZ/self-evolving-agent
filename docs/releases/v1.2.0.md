# v1.2.0 — Stable self-hosted agent foundation

**A self-hosted AI agent that operates Ubuntu, rewrites its own source, and restarts itself.**

![demo](https://raw.githubusercontent.com/xieshengGZ/self-evolving-agent/main/docs/assets/demo.gif)

## Highlights

- **Stable kernel** — FastAPI + one agent loop, with tools behind a small registry.
- **Hot-reloadable plugins** — tools, planners, classifier, context sections, HTTP ops.
- **Plan state machine** — `planning → executing → verifying → done/replan`, with deterministic acceptance checks.
- **Durable state** — SQLite stores sessions, messages, events and plans; large outputs go to artifacts.
- **SSE streaming** — browser gets tool output and state changes without polling.
- **Self-update** — backup, syntax check, `execv` restart, automatic rollback.
- **Context budget** — priority sections, token accounting, compaction hook, artifact offload.
- **P0 guardrails** — concept questions stay in chat mode; plans cannot invent deliverables; invalid actions get a targeted repair prompt.

## Install

```bash
git clone https://github.com/xieshengGZ/self-evolving-agent.git
cd self-evolving-agent
./install.sh
```

Requires Ubuntu 22.04/24.04, Python 3.12+, systemd, and a DeepSeek API key.

## Safety

This is a single-user, trusted-host tool with shell access. Use a disposable VM, a non-root service user, and a reverse proxy with TLS. Read [SECURITY.md](https://github.com/xieshengGZ/self-evolving-agent/blob/main/SECURITY.md).
